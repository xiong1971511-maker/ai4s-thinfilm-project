## 实际运行的验收与证据

环境：Linux，Python 3.12.14，NumPy 2.5.3，PyTorch 2.14.0+cpu，Matplotlib 3.11.2。仓库锁定依赖实际安装成功。

- `python -m unittest discover -s tests -v`：17/17 通过，记录 `verification/unit_tests.txt`。
- `scripts/check_tmm.py`：Fresnel、网格、反射率范围及无损能量守恒通过，最大能量误差 4.44×10⁻¹⁶。
- `scripts/verify_submission.py`：21/21 通过；保存 `verification/submission_verification.json`。
- 全部 5000 组×41 点数据重算与保存值最大差 8.88×10⁻¹⁶；训练/验证/测试划分完全相同。
- 已发布 Linear 检查点复算：验证 MSE 0.0001652088104；测试 RMSE 0.0113750025，MAE 0.0082906233，与论文取舍精度一致。
- 全部 10000 个候选×41 点 TMM 重算最大差 7.77×10⁻¹⁶；候选重新生成完全相同且与数据集无完全重复结构。
- 跨平台 Float32 候选推断最大差 3.58×10⁻⁷；重跑筛选仍得到相同短名单、41 个越界预测和相同最终 Top 5。
- 全池极值、短名单与全池 Top 5 重合数、全部四规模损失历史、测试最大 RMSE 行 3477 均与保存结果一致。
- `scripts/evaluate_mlp.py`、`scripts/screen_designs.py` 和修正后的全池审计入口实际运行通过。
- 全部 3 张论文组合图已从发布材料重新生成。最终 Word 经渲染导出 PDF 后逐页检查 6 页：中文、公式、表格、图注、页码无缺字、遮挡、越界或孤立图注。

没有在本次验收重复原 Windows 的全部 Linear 训练过程；四个规模的原始训练历史和指标已核对，主检查点已独立评估。另运行了四规模 Sigmoid 对照，发现平台间轨迹变化；该新实验未作为原对照记录补入论文。读者可依据 README 的明确参数从头运行训练。
