# Figure font

AI4S Figure CJK Regular is a renamed glyph subset of Noto Serif CJK SC Regular by the Noto Project authors, distributed under the SIL Open Font License 1.1. The original font copyright and license metadata are retained. Only characters used by the bilingual figure script are included.

Source: https://github.com/notofonts/noto-cjk/tree/main/Serif

The plotting script loads the local font directly. SVG labels are exported as vector paths so Chinese labels remain visible without a separately installed font.
